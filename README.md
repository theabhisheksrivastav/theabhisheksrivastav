## Featured Projects

### HostelHub — Multi-Tenant Property Management SaaS
A full SaaS platform built for hostel and property operators. Supports multiple tenants on a single deployment with isolated data, custom subdomains, and tenant-scoped admin panels.

- NestJS backend with PostgreSQL, Prisma ORM, and Redis caching
- Tenant resolution via subdomain middleware with per-tenant context injection
- Role-based access control across Owner, Manager, and Staff roles
- Dockerized with NGINX and GitHub Actions for automated deployments

### Suraksha — Secure QR Verification Platform
A verification system for generating and validating tamper-resistant QR codes tied to identity or document records.

- QR tokens linked to signed payloads with expiry and revocation support
- Audit-logged scan events with actor and timestamp metadata
- Designed for operational trust in low-connectivity environments
